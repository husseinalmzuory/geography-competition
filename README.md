# ميدان الجغرافية

موقع عربي لإدارة مسابقة بين فريقين من ستة طلاب، للمراحل الثانية إلى الرابعة.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا باسم geography-competition.
2. ارفع index.html وstyle.css وapp.js ومجلد assets إلى جذر فرع main.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم main والمجلد / (root)، واضغط Save.

## إدارة المسابقة

- من «إعداد المسابقة» عدّل أسماء الفريقين والأسئلة عند الحاجة.
- اختر الجولة أو ابدأ من السؤال الأول.
- المؤقت لا يبدأ إلا عند الضغط على «بدء المؤقت».
- اكشف الإجابة ثم امنح الدرجات. يمنع زر السؤال احتساب درجاته مرتين، ويمكن التراجع.
- لجنة التحكيم تمنح نقاط جولة الترتيب بعد مراجعة الترتيب الكامل.
- في السرعة يتعاون أعضاء الفريق، ويتحدث شخص واحد. لكل فريق موضوع مختلف و٣٠ ثانية، وتُمنح درجة لكل إجابة صحيحة.
- في موضوع الصخور نقصد أسماء الصخور مثل البازلت والغرانيت، دون المعادن أو التصنيفات الرئيسة.
- تُحفظ أسماء الفريقين والدرجات والأسئلة والتقدم في المتصفح نفسه. المؤقت يعاد إلى مدته الأصلية بعد تحديث الصفحة.
- لوحة الدرجات تسمح بالتصحيح اليدوي. التغييرات اليدوية مستقلة عن سجل احتساب السؤال.
- لا توجد مزامنة بين الأجهزة أو قاعدة بيانات أو حسابات. جهاز واحد يدير الشاشة.
- عند فتح الموقع على شاشة القاعة، استخدم زر ملء الشاشة. الصور مخزنة ضمن المستودع والخط الخارجي له بديل محلي.
